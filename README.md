## ✨ Features

- Stream music from YouTube Music
- No ads, no subscription required
- Download songs for offline playback
- Synchronized lyrics support
- Discord Rich Presence integration
- Last.fm scrobbling
- Beautiful Material You design
- Stats and listening history
- Sleep timer

## 🛠 Built With

- Kotlin & Jetpack Compose
- ExoPlayer / Media3
- Room Database
- Hilt (Dependency Injection)
- InnerTube API
